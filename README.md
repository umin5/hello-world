# hello-world
Ce référentiel est destiné à pratiquer le flux GitHub

## Vous pouvez apporter et enregistrer des modifications aux fichiers de votre référentiel. Sur GitHub, les modifications enregistrées sont appelées commits. ##.
Chaque commit est associé à un message de commit, qui est une description expliquant pourquoi une modification particulière a été apportée.
Les messages de validation capturent l'historique de vos modifications afin que les autres contributeurs puissent comprendre ce que vous avez fait et pourquoi.
